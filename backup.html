데이터 백업 및 복원 전용 페이지

📥 1. 백업 파일 저장

앱에서 데이터 백업 및 복원 → 백업 사이트 열기를 누른 다음, 아래 버튼을 눌러 클립보드의 데이터를 가져오세요.

아직 백업 데이터가 확인되지 않았습니다.

📤 2. 백업 파일 확인 및 복원 준비

기존에 저장한 JSON 백업 파일을 불러오면 내용을 확인할 수 있습니다. 실제 복원은 앱의 데이터 백업 및 복원 창에서 JSON 파일을 선택하세요.

이용 안내
• 백업 파일은 휴대전화 또는 컴퓨터의 다운로드 폴더에 저장됩니다.
• 클립보드 불러오기에 실패하면 입력란을 길게 눌러 붙여넣은 뒤 [붙여넣은 백업 데이터 확인]을 누르세요.
• 복원할 때는 앱에서 저장된 JSON 파일을 선택하세요.
